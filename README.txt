FIRE EAGLE WEBSITE

Project: Fire Eagle Website
Status: Final Version

ABOUT
-----
This package contains the complete source files for the Fire Eagle website.

The website includes:
- 8 website pages
- Responsive layout
- CSS styling
- JavaScript functionality
- Page transitions/animations
- Images and other required assets
- Self-contained SVG social media icons
  (Facebook, Twitter and Instagram)

PROJECT STRUCTURE
-----------------
index.html
css/
js/
images/
fonts/
[other project files and folders]

HOW TO RUN LOCALLY
------------------
1. Extract the ZIP file.
2. Open the project folder.
3. Open "index.html" in a modern web browser.
4. The website should load with all included local assets.

IMPORTANT
---------
Keep the existing folder structure unchanged.
Do not rename, move, or delete CSS, JavaScript, image, font,
or other asset files unless the corresponding file paths
in the website code are also updated.

DEPLOYMENT / HOSTING
--------------------
For online deployment, upload the complete project folder
to a suitable web hosting service.

The website is a static website and can be deployed using
services such as Netlify or other static hosting providers.

MAIN ENTRY FILE
---------------
index.html

SOCIAL MEDIA ICONS
------------------
Facebook, Twitter and Instagram icons are included as
self-contained SVG assets so they do not require an
external icon-font service or internet connection to display.

FINAL DELIVERY
--------------
This package contains the final website source files.

For any future modifications, please keep the original
project structure and asset paths intact.
